# 拼多多下单助手（Chrome 插件）

按预设的商品链接 / 规格 / 数量，在拼多多页面上**模拟人工操作**下单；下单后由后台定时轮询订单列表，一旦发货就通知你。

## 功能

- 📋 **预设商品**：在设置页维护商品链接 + 规格关键词 + 数量
- 🖱 **拟人化点击**：随机延时、带轨迹的鼠标移动，模拟真人操作
- 💳 **到支付页停下**：订单提交后停在支付页，由你手动确认支付
- 📦 **自动查发货**：每隔 N 分钟后台打开订单列表，发现发货推送桌面通知


## 安装

1. 打开 Chrome → 地址栏输入 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选中这个工程目录
4. 看到「拼多多下单助手」出现在列表里即安装成功

**图标文件**：建议在 `icons/` 目录放 `icon16.png`、`icon48.png`、`icon128.png` 三张图标（任意拼多多主题图都可以），没有也能跑，只是通知可能没图标。

## 使用

1. 先在 Chrome 里**手动登录拼多多**（<https://mobile.yangkeduo.com>）。插件不负责登录，用的是你浏览器自己的 Cookie。
2. 点插件图标 → 「设置」，添加你要下单的商品：
   - **商品链接**：从拼多多复制，推荐 `mobile.yangkeduo.com/goods.html?goods_id=xxx` 这种移动端 URL
   - **规格关键词**：规格文字，多个用空格分开，如 `黑色 XL`。插件会按关键词点中规格按钮
   - **数量**：下单份数
3. 调整发货轮询间隔（默认 2 小时）和拟人化延时参数
4. 回到弹窗，点商品后面的「下单」按钮：
   - 新开标签页跳到商品详情
   - 自动点「立即购买」→ 选规格 → 调数量 → 点「确定」→ 到结算页点「提交订单」
   - 跳到支付页**停下**，顶部横幅提示你手动完成支付
5. 支付完就可以关掉标签页。订单会出现在插件弹窗的「订单」区
6. 发货后你会收到桌面通知，弹窗里的订单徽标也会变成「已发货」

## 注意事项

### 关于 DOM 选择器

拼多多页面结构**会随时变**。如果某一步卡住（控制台 `[PDD]` 开头日志里能看到报错），需要去 [content/order-flow.js](content/order-flow.js) 调整对应环节的选择器或文本关键词：
- 「立即购买」按钮文本
- 规格面板里的「确定」按钮
- 数量 `+` 按钮
- 「提交订单」按钮

[content/order-check.js](content/order-check.js) 的订单抓取靠「待发货/已发货/待收货/已完成」这几个状态文字锚定，相对稳。

### 关于拟人化

默认 400–1500ms 的随机延时足够骗过基础风控，但**抢购场景**（秒杀）里这速度肯定赶不上。如果用于秒杀，建议把两个延时都调到 50–200ms，并且在页面上提前打开好。

### 关于支付

插件**不会自动支付**。PDD 支付通常需要微信/支付宝扫码或 APP 授权，这一步没法完全自动化，也更安全——避免误下单。如果你想完全自动，可以把设置里「到达支付页就停下」关掉，但要自己保证支付方式是免密的。

### 关于轮询频率

轮询间隔建议 ≥ 60 分钟。过频繁地打开订单列表页可能触发拼多多的异常检测。

### 调试

- 弹窗/设置页的问题：在弹窗上右键 →「检查」看 DevTools
- 下单流程的问题：在打开的拼多多标签页按 F12 看 Console，筛 `[PDD]` 前缀
- 后台任务问题：`chrome://extensions` 页面 → 本扩展 → 「检查视图：Service Worker」
